# Offline interactive demo

Open [index.html](index.html) directly in a browser, or enable GitHub Pages on branch `main`, directory `/docs`.

This demo uses static synthetic data and scripted responses only. It demonstrates navigation, a watchlist, paper trading, factor-strategy exploration, sample AI research, rule creation, community viewpoints and educational investment frameworks. It does **not** connect to the backend, live data, or any paid AI API.
