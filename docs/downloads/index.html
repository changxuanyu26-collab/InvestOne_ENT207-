After downloading

  1. Extract the downloaded ZIP to a folder.
  2. Windows: double-click Open InvestOne.cmd. Mac: double-click Open InvestOne.command. Linux: launch Open InvestOne.sh (may require executable permission).
  3. In the browser, sign in with 红豆薏米水 or RedBeanCoix and enter your own Highway API Key.
  4. In Settings, check live data connections. The upstream financial providers may be delayed or unavailable on specific networks.
Security transparency: the current Mac builds are not Apple-signed/notarized, and Windows builds are not Authenticode-signed. Your OS may display a security warning; a download button cannot bypass this. Download only from this official project and verify the SHA-256 checksums. Do not disable system-wide security protections.
The public interactive demo uses synthetic market data and scripted AI. The downloadable app uses live external financial-data adapters and the user's own API Key. Paper trading only; no broker execution or investment advice. Full setup instructions.
